## EX.3: UI-UX-Experiment3

## Aim:
To Heuristic Evaluation of an Existing Website or App

## Algorithm:
1.Select and Compare 2–3 Competitor Apps/Websites

2.Perform Heuristic Evaluation

3.Analyze and Document Findings

4.Propose and Apply Improvements

## Output:

Instagram and YouTube, though both designed for content sharing, differ in how they deliver user experiences. Instagram focuses on quick, visually driven engagement through reels, stories, and posts, supported by a minimal mobile-first interface that encourages short interactions. YouTube, however, prioritizes long-form content and discovery, using its recommendation engine, playlists, and advanced search to provide deeper viewing experiences. While Instagram excels in instant social connectivity, YouTube is stronger in content depth and discoverability. A merged design approach—like Instagram adopting YouTube’s advanced search and categorization, and YouTube integrating Instagram’s sleek interface and real-time engagement tools—could create a more balanced platform. By using Canva prototypes, these improvements can be visualized as redesigned navigation bars, unified search experiences, and hybrid feed layouts, blending the strengths of both apps to enhance accessibility, engagement, and overall usability.
